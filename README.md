# 🔐 Cryptography & Information Security Projects

A collection of three academic projects developed to explore practical concepts of **Cryptography, Information Security, Steganography, and the DES encryption algorithm**.

These projects demonstrate how secure information can be encrypted, hidden, processed, and visualized using different security techniques.

### 📌 Description

A Java-based **Secure Steganography** application that demonstrates how confidential information can be hidden inside digital images.

The project combines the concepts of **Steganography and Cryptography** to provide an additional layer of protection for secret information.

* 🖼️ Hide messages inside images
* 🔍 Extract hidden messages
* 🛡️ Additional security layer
* ☕ Java implementation
* 🖥️ User-friendly interface

# 🔎 Task 3 — Interactive DES Visualizer

### 🔗 Repository

[Interactive-DES-Visualizer — GitHub Repository](https://github.com/ebrahim4070/Interactive-DES-Visualizer?utm_source=chatgpt.com)

### 🌐 Live Demo

[Interactive DES Visualizer — Live Demo](https://ebrahim4070.github.io/Interactive-DES-Visualizer/?utm_source=chatgpt.com)

### 📌 Description

An interactive educational tool designed to visualize the internal working of the **Data Encryption Standard (DES)** algorithm.

The project makes the complex DES encryption process easier to understand by presenting its major operations step by step.

### ✨ Key Features

* 🔐 DES encryption visualization
* 🔄 Step-by-step DES processing
* 🔑 DES key generation
* 🔀 Initial and final permutations
* ⚙️ Feistel network visualization
* 🔢 16-round processing
* 📊 Interactive visualization

### 🧠 DES Encryption Process

```text
64-bit Plaintext
       ↓
Initial Permutation
       ↓
   L₀ + R₀
       ↓
16 Feistel Rounds
       ↓
Final Permutation
       ↓
64-bit Ciphertext
```

### 🔑 DES Key Schedule

```text
64-bit Key
    ↓
Permuted Choice 1
    ↓
C₀ + D₀
    ↓
Left Circular Shifts
    ↓
Permuted Choice 2
    ↓
Round Keys K₁ ... K₁₆
```

### 🛠️ Technologies

* HTML
* CSS
* JavaScript
* DES Algorithm
* Cryptography
* Interactive Visualization

> ⚠️ **Security Note:** DES is considered obsolete for modern security applications because of its small effective key size. This project is intended for educational purposes. Modern applications should generally use stronger algorithms such as AES.
